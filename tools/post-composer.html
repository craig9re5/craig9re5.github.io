快捷键与 Markdown 帮助
  • 插图：正文里直接 Ctrl + V 粘贴截图，或把图片文件拖进正文，都会自动存到 assets/posts/<slug>/ 并插入
  • 快捷键：Ctrl + B 粗体、Ctrl + I 斜体、Ctrl + K 链接、Ctrl + S 保存（按住 Shift 保存后直接开下一篇）
  • 写列表：回车自动接上一条，在空条目上再按回车就退出列表；Tab / Shift + Tab 缩进和反缩进
  • 选中一段文字后粘贴网址，会自动变成 Markdown 链接
  • 工具栏按钮可以再点一次取消，例如取消加粗或去掉标题
  • 正文里按 Esc 可以移开焦点，这样 Tab 恢复为界面跳转
  • 草稿会自动存在浏览器本地；发布前会弹窗确认分支、待推送提交和本次改动的文件
