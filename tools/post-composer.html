快捷键与移动发帖帮助
  • 🚀 一键发布：点击「发布到博客」或按 Ctrl + Enter，全自动完成保存并推送到 GitHub。
  • 📱 手机发帖 (方案 B)：在手机浏览器打开本页，点击右上角「⚙️ 设置」填入 GitHub Token，即可随时随地拍照写文直接发布！
  • 📷 插图：桌面可直接 Ctrl + V 粘贴截图或拖入；手机可点击工具栏相机直接拍照上传。
  • ⌨️ 常用快捷键：Ctrl + Enter 发布、Ctrl + S 存草稿、Ctrl + B 粗体、Ctrl + K 链接。
